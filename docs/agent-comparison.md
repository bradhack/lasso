# Two agents or one?

This page compares Lasso's Press Room (the Scout researches a fan's question with the Gaffer's MCP tools, then the Gaffer, who has no tools, writes the answer) with one agent given the same tools, rules and time, on the same 27 questions scored by the same checks.
